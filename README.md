# FreshMart | Business Intelligence Dashboard
## Project Overview
FreshMart is an interactive Business Intelligence Dashboard developed using Microsoft Power BI to analyze business performance and support data-driven decision-making.
The project provides insights into sales, profitability, product performance, and business scenarios through interactive visualizations and analytical tools.
## Dashboard Pages
### 1. Sales Overview
- Sales performance analysis.
- Interactive year filters.
- Overall and yearly sales target comparisons.
- Dynamic custom tooltips.
- Sales drill-through analysis.
### 2. Profit Overview
- Profit and profitability analysis.
- Interactive filters.
- Profit drill-through.
- Decomposition Tree for exploring profit drivers.
### 3. Product Analysis
- Product performance evaluation.
- Interactive product filters.
- Comparative analysis.
### 4. What-If Analysis
- Dynamic scenario simulation.
- Adjustable price, discount, quantity, and cost parameters.
- Impact analysis on sales, cost, and profit.
- Reset to default scenario.
## Key Features
- Interactive KPI cards and slicers.
- Custom tooltips.
- Drill-through pages.
- Decomposition Trees.
- Dynamic What-If parameters.
- Scenario comparison and reset.
